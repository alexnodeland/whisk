$ brew tap alexnodeland/tap

GitHub Download Rules reference

Rules, not chores

// ~/.config/whisk/rules.json — hot-reloaded on every save
{
  version: 1,
  targets: [{
    path: "~/Downloads",
    rules: [
      { id: "file-images",
        match: { name: { glob: "*.{png,jpg,heic}" } },
        actions: [{ move: { to: "~/Pictures/Inbox/{date.modified:yyyy-MM}" } }] },
      { id: "trash-old-installers",
        match: { all: [
          { extension: ["dmg", "pkg"] },
          { age: { olderThan: "7d" } },
        ]},
        actions: [{ trash: {} }] },
    ],
  }],
}

Built to be trusted

Watches & ages

FSEvents when things change, timed sweeps as files age into a rule, and a safety-net rescan.

Undo-friendly

Trash, never delete. Dry-run mode previews every action before you commit.

Runaway-proof

Self-write ledger, cooldowns, and action budgets that auto-pause a misbehaving rule.

Shell, safely

Commands run argv-only with a sanitized environment — and only after you approve them once.

Scriptable

whisk://sweep, pause, resume, dry-run — plus a JSONL activity log for your tooling.

Yours in a file

Rules live in a commented JSON5 file you can sync and version. A built-in editor covers the basics.
